# 设计语言

SPA 的视觉、交互和设计流程规则。色值和字体不在这里重复，唯一来源是 `src/nblane/web_ui/frontend/src/theme.ts`。

## 配色与字体

- 深色锁定，不提供浅色主题。底色是靛蓝阶梯（页面、面板、卡片、星图画布四档），正文月白，强调色泥金。
- 绿色只表语义（成功、健康），不做装饰。红色 / 朱砂只用于删除、废弃、过期描边和「今天」标记，不做填充。
- 铭文卡有一组专用 token（深底、细金边、文楷标题、明体正文），在 `theme.ts` 的 `inscription` 导出。项目页的泳道与时间轴 token 在 `boardPalette`。
- 组件一律从 `theme.ts` 引用，不在组件里硬编码色值。

## 身份语法（默认冻结）

以下是 nblane 的识别性语法，默认不改。要改必须先做可交互原型，证明明显优于现状。

- 极坐标俯视星图：首页是一张转动的星盘。北极星居图心，目标是北斗七座（天枢…摇光，超出走星表），技能域是外环星官，项目是围绕目标的行星，近期证据是客星，其余证据是尘埃带。
- 两态：图态是「刻」（石刻随盘转，已定之史），境态是「写」（展开、流动，未竟之事）。滚轮或印章切换。
- 命名层：图面默认只刻古名，真实文字只在铭文卡和星表里，所以图面天然可公开。「显真」开关把古名整体替换为真名（替换制，不并列）。
- 石刻质感：活跃对象泥金实心可拖，已定对象月白线刻只读。已完成目标是刻痕星，钉在盘上、灭金光。
- 印章家族：星表「+」、日课印、显真印、境 / 图印、卜印同一套斑蚀篆刻语言，44px 模数、细双圈、悬停金晕。日课印白文 = 未打卡，朱文 = 已打卡。
- 铭文卡：点任意对象出卡；卡是阅读态，「重刻」翻成编辑态，保存后落印。没有独立编辑页。
- 编年史（项目页 `view=story`）：只读回放。S 形牛耕式行排布、最新在上，五种笔法（done 刻点、doing 描金条、queue 虚框、someday 虚点、断轴 `///`），无里程碑、无斑马纹。时间轴负责规划，编年史负责回放。
- 2026-09-24 讨论过境态改斜视相机，不采纳：与平面石刻语法冲突，也不治任何已报痛点。

## 交互约定

- 三级触达：L1 板上直操作（拖拽、点打卡、行内快添，零跳转）；L2 卡片与抽屉（全字段，破坏性动作只住这层）；L3 索引与历史（归档带、时间轴历史层，完备但视觉降级）。
- 创建动作不超过一次点击。快添成功后直接打开详情卡。
- 不静默丢数据：防抖写入在关闭和切换时冲刷；后台刷新不覆盖正在编辑的草稿；412 冲突要么用新 ETag 合并重试，要么点名冲突字段，整列表替换类写入不盲重试。
- 删除三件套：后果预告 + 逐字输入名称 + 「记入大事记」默认不勾。家务删除不混入叙事。
- 用户手势永远赢：定位、动画进行中，拖拽和滚轮立即接管。
- Esc 一键回到纯图或关闭当前浮层，不分层。
- 键盘可达：列表、卡片、热力图格、归档项都可 Tab 到并用 Enter / Space 操作；方向键与 j/k 同义。
- 手机可用：390px 宽无横向溢出；顶栏不折行（窄屏只留图标，名称保留为 aria-label）；悬停才出现的菜单在触屏上常显；触控目标不小于 44px。
- 安静反馈：高频成功操作（如拖拽）不弹通知，错误就地显示在出错的字段或卡片上。
- 日期统一显示 `YYYY-MM-DD`，不用浏览器本地化的原生日期控件。
- 动效尊重 `prefers-reduced-motion`：脉冲、钤印、呼吸一律关闭。
- 跨域一律跳转不内嵌：项目页不改目标（首页重刻），不评证据（证据页），不改技能（技能树页）。

## 设计流程

- 新方向先审批：先用一段话描述 + 参考位置或链接来提案，获批后才做原型。
- 动效在运动中评判：任何动画（过渡、粒子、活场景）必须做成可交互 / 实时演示（先例：星图 playground），不凭静态截图判断。
- 增量直接改真东西：对已上线设计的增量（标签、命名层、移除）不做 mockup，先用文字对齐位置和效果，再在隔离栈（18504）实现供上手评审。
- 新设计以生产质感为基线；mockup 验证构图和概念，不重新定义笔触。
- 每个改动说明它消除哪个痛点：不接受「可能更好看」的提案。纯审美实验先进原型。身份语法默认冻结，除非原型证明明显更好。
