# 首页：成长星图

首页 `/p/<档案>/home` 是一张全屏星图，一眼看到北极星、目标、项目、证据和技能的整体状态。目标管理也在这里完成。旧的 `/goals` 链接会跳到首页。

## 星图上有什么

| 星 | 代表 | 数据来源 |
|----|------|----------|
| 北极星 | 长期方向，位于图心；未设置时是一个脉冲的空圈 | `SKILL.md` 的 Identity 区 |
| 目标恒星 | 进行中的目标，按座次赐名天枢、天璇、天玑、天权、玉衡，最多 5 颗；开阳、摇光是空心虚位 | `goals.yaml` |
| 刻痕星 | 已完成的目标，最多 5 颗，不发金光 | `goals.yaml` |
| 行星 / 卫星 | 项目和它的任务（每颗行星最多挂 5 颗卫星，卫星不可点） | `project-board.yaml`、`kanban.md` |
| 客星 | 近 30 天的证据，最新 4 条一定显示 | `evidence-pool.yaml` |
| 星官 | 外环扇区，一个扇区一个技能类目，刻古星官名；已点亮的技能可以点 | `skill-tree.yaml` |

超过座位数的目标不上图，在星表里能看到。星图底部的简报行写着待评审的客星数、在轨行星数，以及本月新立目标、新点亮技能等编年统计。浏览器不支持 WebGL 时只显示这行简报。

## 操作

- 悬停：显示星名和简要信息。
- 点击：右侧打开铭文卡，点空白处关闭。
- 拖拽（桌面）：左右拖动旋转星盘。星盘约一小时自转一圈，有操作时暂停。
- 滚轮：切换图态（石刻星盘）和境态（水墨星野），不是缩放。
- 手机：单指平移、双指缩放。
- Esc：关闭星表、铭文卡、编辑和占卜，回到纯图。
- 系统开启「减少动态效果」时不播放动画。

右下角四枚印章：

- 卜：占卜。
- 真：显真开关。默认只显示古名，开启后只显示真名（目标、项目的真实标题）。项目页的北极星徽章用同一个开关，偏好记在浏览器里。
- 境 / 图：切换两种画面。
- ＋：打开星表。

## 星表与目标管理

点「＋」打开星表，分四节：北极星、进行中、暂停、已镌刻。

- 点某一行：星盘把这颗星转到正北，并打开铭文卡。在图上点星，星表对应行同步高亮。
- 键盘：↑ / ↓ 或 j / k 移动，Enter 开卡。
- 新增目标：点「＋ 新增目标」，填标题（必填）、摘要、目标日期，点「落印」。起始日期自动填当天，写入 `goals.yaml`。

目标不能在首页删除，要收尾就把状态改成「暂停」或「已镌刻」。

## 铭文卡

点任意可点的星都会打开铭文卡：

| 星 | 显示 | 跳转 |
|----|------|------|
| 北极星 | 铭文全文、简称、可见性 | 无 |
| 目标 | 状态、星位、起止日期、铭文 | 前往项目泳道 → |
| 行星 | 在轨 / 归档、所属目标、任务数、进度、时间范围 | 前往项目 → |
| 客星 | 类型、强度、日期、评审状态、摘要 | 前往证据 → |
| 星官 | 类目、状态、关联证据（最多 3 条） | 前往技能树 → |

北极星和目标卡上有「重刻」按钮，可以直接编辑：

- 北极星：全文、简称（图面与列表用）、可见性（可公开 / 仅本地）。可见性只影响公开产物，助手始终能看到全文。保存时只改写 `SKILL.md` Identity 区的这几行。
- 目标：标题、摘要、起始日期、目标日期、状态（进行中 / 暂停 / 已镌刻）。

点「落印」保存，「收起刻刀」取消。

## 日课印（习惯打卡）

左下角「日课」一列小印，每个习惯一方，印面取一个字。白文表示今天没打，朱文表示已打。

- 点印面：今天打卡。
- 悬停或长按：看全名、本周 7 天打卡点和连续天数。
- 右键或长按已打卡的印：「销印」，撤销今天最近一次打卡（会先确认）。

打卡记在 `activity-log.yaml`。首页不能新建或编辑习惯，习惯和阶段计划在 [项目页](projects.md) 管理。没有习惯时这一列不显示。

## 占卜

点「卜」印，星尘聚成卦象，随后滑出卦辞卡（卦名、卦辞、解读）。

- 戏占：默认，打开即起卦。
- 正占：输入一个问题后点「起卦」，会对照当前目标找出技能缺口。发现缺口时卡片上多一个「化为任务」按钮，把每个缺口变成看板 Queue 里的一条「学习 X」任务。

同一天、同样的星图状态得到同一卦。卦辞优先由 AI 生成，AI 不可用时用规则文本，卡片上标「离线卦」。占卜本身不写任何文件。

## 编年记录

首页的这些操作会记入编年（`chronicle.yaml`，只追加）：新增目标、目标改名、目标完成、北极星重刻。技能在技能树页晋升、在项目页删除时勾选「记入大事记」也会各记一条。星图底部简报行的本月统计读这份记录。按时间回看任务进展用项目页的「大事记」视图，见 [项目](projects.md)。

## 写入了哪些文件

| 操作 | 文件 |
|------|------|
| 新增 / 编辑目标 | `goals.yaml`、`chronicle.yaml` |
| 重刻北极星 | `SKILL.md`、`chronicle.yaml` |
| 打卡 / 销印 | `activity-log.yaml` |
| 化为任务 | `kanban.md`（并同步项目归属） |
| 显真偏好 | 浏览器本地存储 |

星图的整体设计与身份语法见 [成长图](../product/growth-graph.md) 和 [设计语言](../product/design-language.md)。
