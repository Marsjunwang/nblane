# Web 使用手册（SPA 总览）

nblane 的 Web 界面是一个单页应用（SPA），由 `nblane.web_api` 在同一进程里提供页面和 `/api/v1`。论文库与阅读器由 Reader API（8502）提供，SPA 用 iframe 嵌入。安装与启动见 [安装与配置](setup.md)，生产部署见 [腾讯云部署](deployment-tencent-cloud.md)。

## 登录

- 未配置 `NBLANE_AUTH_FILE` 时不需要登录，直接进入档案列表。
- 开启鉴权后，未登录访问任何页面都会跳到 `/login`，登录后回到原来要去的页面。
- 账号只分三类：本人、助手服务账号（`agent: true`）、管理员。管理员才能看到设置里的「系统」分区。
- 顶栏「退出登录」只在开启鉴权时显示。

## 档案列表

`/` 列出你能访问的档案。每张卡片显示档案名、技能 schema、技能节点数和当前目标，点卡片进入该档案首页。还没有档案时用 `nblane init <name>` 创建。

## 导航

进入档案后，左栏是 8 个工作区，地址都在 `/p/<档案>/` 下：

| 左栏 | 路由 | 用途 | 手册 |
|------|------|------|------|
| 首页 | `home` | 全屏星图、星表与目标、习惯印、占卜 | [首页](home.md) |
| 项目 | `projects` | 看板 / 时间轴 / 编年史，任务与项目 | [项目](projects.md) |
| 技能树 | `skill-tree` | 技能状态、铭文卡、技能进阶 | [技能树](skill-tree.md) |
| 证据 | `evidence` | 证据五阶段、审阅、待补强、结晶 | [证据](evidence.md) |
| 研究台 | `research` | 论文库、论文概览、阅读器、来源 | [研究](research.md) |
| 内容工作台 | `content` | 文章写作与发布（BlockNote 编辑器） | [内容工作台](content.md) |
| 求职工作台 | `career` | 简历、目标岗位、导入简历、JD 定制 | [求职工作台](career.md) |
| 公开站点 | `public-build` | 构建与发布公开站 | [公开站点](public-site.md) |

左栏底部有「档案列表」返回 `/`。桌面端左栏默认是只显示图标的窄栏，悬停看名称，点底部「展开导航」切换为带文字的宽栏，选择会被记住。

顶栏从左到右：

- 档案名徽标：当前所在档案。
- 车间：在新标签页打开 `/workshop` 网页终端，见 [车间](workshop.md)。
- 助手：`/assistant`，OpenClaw 状态、接入方式与撤销日志，见 [助手](assistant.md)。
- AI 异常：只在有异常时出现（红色角标显示条数），见下文。
- 设置：`/settings/<分区>`。
- 当前用户名与「退出登录」。

## 主要路由

| 路由 | 页面 |
|------|------|
| `/login` | 登录 |
| `/` | 档案列表 |
| `/p/<档案>/home` | 首页星图 |
| `/p/<档案>/projects?view=kanban\|timeline\|story&group=goal\|activity` | 项目 |
| `/p/<档案>/skill-tree` | 技能树 |
| `/p/<档案>/evidence?stage=…` | 证据 |
| `/p/<档案>/research`、`research/library`、`research/papers/<id>`、`research/papers/<id>/read`、`research/sources` | 研究台、论文库、论文概览、阅读器、来源 |
| `/p/<档案>/content/*` | 内容工作台 |
| `/p/<档案>/career/*` | 求职工作台 |
| `/p/<档案>/public-build` | 公开站点 |
| `/workshop` | 车间终端 |
| `/assistant` | 助手 |
| `/settings/<分区>?profile=<档案>` | 设置 |

旧链接会自动跳转：`health`、`evidence-review` → 证据，`kanban`、`project-board` → 项目，`goals` → 首页，旧的 Streamlit 页面地址（如 `/Skill_Tree`、`/pages/1_Skill_Tree.py`）跳到对应的新页面。

## 手机端

- 宽度小于约 768px 时左栏收起，点顶栏左侧的汉堡按钮打开抽屉导航，选中一项后抽屉自动关闭。
- 顶栏按钮只显示图标，不换行。
- 设置页的左侧目录变成顶部两个下拉框：分区和档案。
- 车间终端有手机快捷键栏，见 [车间](workshop.md)。

## AI 异常抽屉

顶栏红色三角图标打开右侧抽屉，只列出失败、冲突或被阻止的 AI 操作（来源、动作、时间、错误信息）。可以单条「忽略」，也可以勾选或全选后「忽略选中」；「刷新」重新拉取。没有异常时图标不显示。

## 设置

设置分三组：

- 系统（仅管理员，整个部署共用，修改立即生效）：AI 服务、本地服务、车间终端、助手与备份、账号管理。
- 档案（只影响所选档案，改完点保存）：通用、研究与阅读、AI 路由。
- 账号（每个人都有）：我的账号。

有未保存修改时离开分区会弹出确认。各分区的具体选项写在对应功能文档里：AI 服务与 AI 路由见 [AI 架构](../architecture/ai-architecture.md)，本地服务、研究与阅读见 [研究](research.md)，车间终端见 [车间](workshop.md)，助手与备份见 [助手](assistant.md)。

### 我的账号

`/settings/account`：

- 修改密码：输入当前密码和新密码（至少 10 位）。改完后其他设备上的登录全部失效，当前浏览器保持登录。
- 登出所有设备：所有浏览器都要重新登录。
- 管理员新建或重置过密码的账号，首次登录只能进这一页，改完密码才能用别的页面。
- 本地模式（没开登录）下这里没有可操作的项。

### 账号管理

`/settings/accounts`，仅管理员：

- 新建用户：用户名、显示名、角色（成员 / 管理员）、初始密码，可以同时用模板建一个同名档案，这时再选领域（机器人、自动驾驶，或管理员放进数据目录 `schemas/` 的领域，默认机器人）。新用户首次登录必须改密码。加领域的方法见 [技能树 Schema](../reference/skill-tree-schema.md#新增领域-schema)。
- 编辑：显示名、角色、能访问的档案。
- 重置密码：设一个新密码，对方所有登录失效，下次登录必须改密码。
- 停用 / 启用：停用后无法登录，已有登录立即失效，档案数据不动。不提供删除。
- 不能停用或降级自己；系统里至少要留一个能登录的管理员。
- 助手服务账号没有密码操作，改为管理 API token：生成时明文只显示一次，可以随时撤销。日常更推荐在「助手与备份」一键生成并配置，不用手动复制。用法见 [OpenClaw 运维](openclaw-ops.md#服务账号凭据)。

账号保存在 `auth/users.yaml`。网页的修改不会立即提交，每天的定时备份会把它提交进私有数据仓库。

### 通用

`/settings/general` 只有「语言」一张卡：

- 界面语言：中文 / English，留空跟随部署默认。
- AI 回复语言：自动 / 中文 / English。

两项保存在所选档案的偏好里（`ai.llm.ui_lang`、`ai.llm.reply_lang`）。SPA 自身文案目前固定为中文，嵌入的论文库和阅读器也按中文打开；界面语言主要影响服务端生成的文案。
