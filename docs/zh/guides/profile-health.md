# Profile Health 使用说明

Profile Health 是只读体检页，用来检查档案可信度、上下文可发布性和公开风险。

## 什么时候使用

- 发布公开内容前。
- 大量修改 evidence、skill tree、project 或 public layer 后。
- 想知道当前 profile 是否有阻断项。

## 推荐流程

1. 查看错误、警告和信息数量。
2. 先处理错误，再处理警告。
3. 按每条 issue 的建议回到 owner 页面修复。
4. 需要把近期活动整理成 evidence 或 next action 时，打开 Review。
5. 修复后刷新本页复查。

## 写入边界

本页不写文件，只提供检查结果和跳转建议。
