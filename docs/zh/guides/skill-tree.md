# 技能树

技能树页 `/p/<档案>/skill-tree` 用来查看和调整每个技能节点的境界。境界的变化应该有证据支撑：证据在 [证据页](evidence.md) 挂到技能上，这里看积累够不够、再决定是否晋升。

## 页面结构

- 页头：各状态数量（学习中 / 扎实 / 精通 / 锁定）和总数，以及所用 schema 与更新时间。
- 搜索框「按标题筛选…」：只按标题匹配，会保留匹配节点的上级并自动展开。
- 左侧：按类目分组的节点列表。
- 右侧：选中节点的铭文卡。

## 类目即星官

每个类目上方有一条星官横幅，与首页星图外环的扇区一一对应：

- 星官小像（真实星官连线）、类目名和星官名。少数类目还没有真实星形，标「拟形·模板」。
- 三态计数：空圈 = 锁定，实点 = 在学，点套圈 = 点亮（扎实与精通合计）。
- 一行星官小传。

类目下是树形节点列表，层级来自 schema 的 `requires`，可以展开或折叠。每行显示状态图形、标题、状态和「证据 N」。已达到进阶门槛的节点会有金色呼吸光。

## 节点铭文卡

点一个节点，右侧打开铭文卡：

- 状态、类目（含星官名）、证据数。
- 进阶：当前境界 → 下一境界、得分 / 门槛进度条、突破证据数。达标时显示「已达进阶门槛」。
- 境界：三档步进器「锁定 / 在学 / 点亮」。
- 关联证据：只读列表（标题、日期、类型），点击跳到证据页并选中该条。

## 调整境界

在「境界」里点一档即写入：

- 锁定 → `locked`，在学 → `learning`，点亮 → `solid`。
- 精通（`expert`）只能经评审得到，这里不能直接设置。对精通节点点「点亮」会降为扎实。
- 晋升（境界变高）会记入编年（`chronicle.yaml`），首页简报行会统计。

写入 `skill-tree.yaml`，并同步 `SKILL.md` 的生成块。如果文件在别处被改过，保存会提示冲突，刷新后重试。

## 技能进阶

进阶分由挂在该技能上的证据累计：

| 证据分量 | 分值 |
|----------|------|
| 弱 / 未评级 | 1 |
| 中 | 10 |
| 强 / 高可信 | 100 |
| 突破证据 | 额外 +1000 |

| 晋升 | 门槛 |
|------|------|
| 锁定 → 在学 | 10 |
| 在学 → 扎实 | 30 |
| 扎实 → 精通 | 100 |

得分达到门槛，或至少有一条突破证据，就算可进阶。可进阶只是提示，不会自动升级，晋升由你在「境界」里确认。证据的分量和突破标记在 [证据页](evidence.md) 设置。

## 不在这里做的事

- 挂载 / 取消证据：在证据页详情卡的「技能关联」里操作。
- 节点备注和内联证据：页面不显示也不编辑，需要时用 CLI（见 [CLI 参考](../reference/cli.md)）或直接改 `skill-tree.yaml`。
- 新增节点：改 `skill-tree.yaml` 或所用 schema，见 [技能树 schema](../reference/skill-tree-schema.md)。
- 领域：内置机器人和自动驾驶两套，类目与星官随所用 schema 变化（自动驾驶有 13 个类目，规划对应北斗、安全对应紫微右垣）。换领域见 [选择与更换领域](../reference/skill-tree-schema.md#选择与更换领域)。

## 注意

- 升到扎实前，先确认至少有一条中等分量的证据；精通需要强证据。不够时证据页「待补强」会列出来。
- 窄屏下列表和铭文卡并排，比较挤，建议在桌面端使用。
