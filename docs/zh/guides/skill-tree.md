# Skill Tree 使用说明

Skill Tree 是能力状态的编辑页。这里的每一次状态变更都应该能被证据解释，而不是只表达主观感觉。

## 什么时候使用

- 更新技能节点状态、备注和内联证据。
- 把共享证据池中的条目挂到一个或多个技能节点。
- 检查某个 solid / expert 状态是否缺少足够强的证据。

## 推荐流程

1. 先确认当前目标，避免把无关技能误判为当前重点。
2. 找到技能节点，更新状态和备注。
3. 轻量事实可以写内联证据；可复用、可审阅的事实应进入 evidence-pool。
4. 证据强度、置信度、项目引用和公开准备度在 Evidence Review 中维护。
5. 保存后检查 SKILL.md 生成块是否同步。

## 写入边界

本页会写入 `skill-tree.yaml`、`evidence-pool.yaml`，并尝试同步 `SKILL.md` 中的生成块。

## 注意事项

- `locked` 到 `learning` 可以很轻，但升到 `solid` 或 `expert` 前应先补证据。
- 同一证据支撑多个技能时，优先使用证据池引用，避免复制粘贴导致事实漂移。
- 公开 claim 不应直接来自技能状态，应先经过 Evidence Review。
