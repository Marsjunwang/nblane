# Output Studio 使用说明

Output Studio 负责从已审阅 evidence、accepted claims 和 research provenance 生成可追溯公开输出。

## 什么时候使用

- 从证据或 claim 生成博客草稿、简历 bullet 或项目更新。
- 编辑公开 Profile、Blog、Resume、Known Info。
- 检查输出是否能追溯到来源。

## 推荐流程

1. 先选择 reviewed evidence 或 accepted claims。
2. 生成候选预览。
3. 人工确认后创建草稿。
4. 在 Blog/Profile/Resume/Known Info 中编辑内容和引用。
5. 去 Public Build 校验、预览和构建。

## 写入边界

本页写入公开输出相关 YAML / Markdown 文件，但不负责构建静态站点。

## 注意事项

Blog tab 会保留当前 tab 状态，内部操作不应跳回从证据生成页。
