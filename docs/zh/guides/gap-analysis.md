# Gap Analysis 使用说明

Gap Analysis 把一个任务映射到技能树，帮助你判断当前能力缺口和学习顺序。

## 什么时候使用

- 开始一个复杂任务前，想知道需要哪些技能。
- 想让 Agent 或自己更清楚下一步学习顺序。
- 完成任务后，需要判断哪些技能可以更新状态。

## 推荐流程

1. 用自然语言具体描述任务。
2. 保留规则匹配，必要时开启 AI 首轮匹配。
3. 如果任务与当前目标强相关，启用 current goal context。
4. 查看匹配节点、依赖闭包和建议下一步。
5. 完成任务并有证据后，再应用技能状态更新。

## 写入边界

本页默认是分析页。只有你显式应用状态更新时，才会写入 `skill-tree.yaml`。

## 注意事项

Gap Analysis 不替代 Evidence Review。能力状态升级仍需要证据支撑。
