# 内容工作台使用说明

内容工作台用来写博客：一个文章库，加一个全屏编辑器。它只读写博客文件，不读证据、断言、技能树或看板。
文章写完点「发布」进入公开层；真正上线在[公开站点](public-site.md)完成。

## 入口

| 页面 | 路由 | 能做什么 |
| --- | --- | --- |
| 文章库 | `/p/<name>/content` | 搜索标题/摘要/标签，按状态（草稿 / 已发布 / 已归档）筛选，按日期或标题排序，新建、删除文章。 |
| 编辑器 | `/p/<name>/content/<slug>` | 全屏 BlockNote 编辑器，编辑一篇文章。 |

新建文章只需填标题，系统据此生成文章地址（`/blog/<slug>/`），之后可以改标题。测试数据默认隐藏，
文章库里有开关可以显示。

## 编辑器

- **三种模式**：编辑（富文本）、Markdown（源码）、预览（按公开站样式渲染）。
- **自动保存**：停笔约 1.5 秒自动保存，`⌘/Ctrl+S` 立即保存。保存只写文件，备份推送在后台进行，不用等网络。
- **文章在别处被改过**：自动保存暂停，你的修改留在编辑器里，可以「保留我的版本」覆盖，或「加载最新版本」放弃本地修改。
  网络断开导致没收到保存结果时，编辑器会先核对服务器上的内容，一致就继续，不会误报冲突。
- **本地草稿**：每次修改都会同时存在这台设备的浏览器里。页面被关掉、刷新或登录过期后再打开，
  顶部会提示「发现未保存的本地草稿」，可以恢复或丢弃；服务器保存成功后本地草稿自动清掉。
- **防误清空**：正文从有内容变成全空时不会自动保存，顶部提示「正文已被清空」，可以恢复正文，或确认保存为空白。
  打开文章后按撤销不会撤掉文章本身。
- **登录过期**：一直在用就会自动续期；闲置超过 12 小时才过期。过期时在当前页弹窗重新登录，编辑器和没保存的修改都还在，登录后自动补存。
- **块**：除标题、列表、引用、代码等常用块，斜杠菜单 `/` 还有公式（LaTeX）、视频、图示（Mermaid 或图片）。
- **媒体**：在「文章设置 → 媒体」上传图片或视频，插入到光标处；也可以把图片直接拖进正文。
  图片支持 png / jpg / webp / gif，单个不超过 10 MB；视频支持 mp4 / webm，单个不超过 25 MB，更大的用外链。
  媒体存在 `media/blog/<slug>/`，可以一键设为封面。
- **文章设置**：摘要（发布必填，显示在博客列表和分享卡片上）、标签、日期、封面、可见性（草稿 / 已归档）。
- **快捷键**：`⌘K` 跳转到其他文章，`⌘⇧O` 目录，`⌘⇧F` 专注模式，`⌘⇧.` 文章设置与媒体。另有加宽版面开关。

## 删除文章

文章库每行右侧的垃圾桶按钮，或编辑器「文章设置」底部的「删除文章」，都会打开确认弹窗。
弹窗说明后果，必须逐字输入当前文章标题才能确认；「记入大事记」默认不勾选，勾选后追加 `content.deleted` 记录。

删除会移除 Markdown 正文、BlockNote 编辑模型和公开目录中的文章条目，清除这台设备的本地草稿，
并刷新文章列表；编辑器会返回文章库。未保存的修改会丢弃。图片、视频和分享卡片设置保留，避免影响其他文章。
删除期间自动保存暂停，取消后恢复；文章在别处被修改时会阻止删除，必须加载最新文章后重新确认。
删除无法在工作台撤销；已有 Git 备份时可从备份找回。已上线文章需要到「公开站点」重新发布，才会从网站移除。

## AI 辅助

AI 只给候选，你确认后才写入；正文从不被 AI 直接改写。没配置对应服务时，入口会显示不可用原因。

- **选区改写**：选中一段文字，格式工具栏里的 AI 菜单有润色、精简、扩写、调整为专业语气、翻译。
  结果在对话框里可以对比、编辑，「接受并替换」才替换选中文字。AI 处理期间原文被改过，则不替换。
- **标题、摘要与标签建议**：在文章设置里生成，点选即填入。发布检查提示缺摘要时，也可以直接「AI 写摘要」。
- **AI 封面**：基于标题、摘要和标签生成封面候选，可加一句画面描述，图中不含文字，约 30–90 秒。
  「用作封面」把图移进文章媒体并设为封面，「丢弃」删除候选。需要配置图像服务（`VISUAL_API_KEY` 或 `DASHSCOPE_API_KEY`，
  千问 / 通义万相默认复用 `LLM_API_KEY`），配置见 [安装与配置](setup.md)。

这些都是后台任务，关掉对话框不影响服务端继续运行。

## 发布

1. 点「发布」，系统先做发布检查（必填项、封面、媒体引用、危险链接等）。有错误时逐条列出，缺摘要可以当场补。
2. 检查通过后「确认发布」，文章状态变为已发布，进入公开层。
3. 到[公开站点](public-site.md)「发布到线上」后，文章才出现在网站上。

已发布的文章继续编辑会自动保存，下次构建站点时更新到网站。「已发布」菜单里可以在新窗口预览、
去公开站点发布，或「撤回为草稿」（下次构建时从网站移除）。

## 发到小红书 / X

「已发布」菜单里的「发到小红书 / X」把整篇文章排成 1080×1440 的竖版卡片（3:4），草稿在顶栏分享图标里，需勾选「仍然导出草稿」。

- **风格**：纸感、暖色手帐、深色三选一，按文章记住。
- **封面**：大标题（留空用文章标题，回车换行）、引文、小标签，可选放文章配图。
- **署名和末页**：每页底部署名可选网站域名、自定义文字或不显示；末页可选「致谢」「致谢 + 网址」或不要。不放网址、不署名，别人就不容易从图片找到你的网站。
- **正文**：按句子自动分页，标题不会落在页尾，代码按行、表格按行续页，最后一页太短会和上一页匀开。很长的 `###` 段落按正文排。超过 18 张（小红书单条上限）会提示。
- **文案**：小红书标题（20 字）和正文（1000 字）、X 推文（按 X 规则汉字算 2，上限 280），各有复制按钮。选了「致谢 + 网址」时 X 文案自动附文章链接。配了 LLM 时可以点「AI 写标题和文案」，只填空着的框，不覆盖你写的。
- **导出**：手机上「分享 / 存到相册」走系统分享；电脑上下载 zip，里面是卡片 PNG 和 `xiaohongshu.txt`、`x.txt`。发布由你手动完成，系统不会代发。

## 文件

- 正文：`profiles/<name>/blog/<slug>.md`（Markdown + front matter，公开构建的事实源）。
- 编辑模型：同名 `.blocknote.json`，保存时与 Markdown 一起写入。用外部编辑器改了 Markdown 后，
  建议删掉对应 `.blocknote.json`，让编辑器从 Markdown 重建。
- 媒体：`profiles/<name>/media/blog/<slug>/`。
- 分享卡片设置：`profiles/<name>/social-cards.yaml`（按文章记风格、封面文字、署名、文案）；生成的图片只是缓存，在 `~/.cache/nblane/social-cards/`。
- 视频在 Markdown 里写作 `::video[说明](media/blog/<slug>/demo.mp4)`；Mermaid 图在公开站由 mermaid 运行时渲染，页面带一份静态 SVG 兜底。

命令行写作、媒体与发布见 [CLI 参考](../reference/cli.md)。
