# 证据

证据页 `/p/<档案>/evidence` 管理证据池：把做完的事结晶成证据、确认 AI 预填的评级、挂到技能上，并找出哪些技能证据不够。字段和文件格式见 [证据参考](../reference/evidence.md)。

基本原则：AI 和规则负责预填，人负责确认。没确认的证据停在「待评审」，不会被当成已审阅的事实。

## 页面结构

三栏：

- 左栏：六个阶段，每个阶段常驻计数。
- 中栏：搜索框「按标题或 ID 搜索…」和当前阶段的列表。搜索只作用于待评审、待关联、已入座、已废弃四个列表。
- 右栏：选中证据的铭文详情卡。

窄屏时三栏纵向排列。地址参数 `?stage=` 记录当前阶段，`?focus=<id>` 直接选中某条证据（技能树页跳过来就是这样）。旧链接 `/evidence-review` 进入「待评审」，`/health` 进入「待补强」。

## 六个阶段

| 阶段 | 内容 |
|------|------|
| 待结晶 | 看板 Done 里还没结晶的任务 |
| 待评审 | 还没确认的证据（默认阶段） |
| 待关联 | 已确认、但还没挂到任何技能上的证据 |
| 已入座 | 已确认、并至少挂到一个技能上的证据 |
| 待补强 | 证据不够的扎实 / 精通技能 |
| 已废弃 | 废弃的证据，保留用于溯源 |

每条有效证据只会落在待评审、待关联、已入座之一：确认后去「待关联」挂技能，挂上就进「已入座」。

## 结晶：从完成的任务生成证据

在「待结晶」点某任务的「结晶」，或顶部「从已完成任务结晶」，打开向导：

1. 选 Done 任务（可多选）。每个任务显示完成日期、项目、背景、结果和原文快照。缺 id、缺完成日期、没关联项目、项目没挂目标时会有阻断提示，需要先在 [项目页](projects.md) 补齐。
2. 生成草稿：
   - 规则草稿：立即生成，每个任务一条 `practice` 证据。
   - AI 草稿：后台运行并显示进度，会同时给出分量和技能建议。失败时可以重试，或改用规则草稿。
3. 评级入库：勾选要保留的条目，确认或调整分量，查看原文快照和技能建议，点「入库并标记已结晶」。

入库会一起写入 `evidence-pool.yaml`、`skill-tree.yaml`（技能关联）、`SKILL.md` 生成块和 `kanban.md`（任务标为已结晶），任一步失败整体回滚。结晶不会改技能境界，晋升在 [技能树](skill-tree.md) 由你确认。新证据进入「待评审」。

## 评审：确认预填

在「待评审」选中一条，详情卡上的按钮：

- 接受：标为已审阅。没评分量时会先问一次：接受后在技能进阶里只按「弱」计分。置信度为空时按来源自动填（论文 / 研究来源为高，看板任务 / 日常记录为中，其余为低）。
- 废弃 / 恢复：移入或移出「已废弃」。列表行悬停也有快捷按钮。
- 编辑：改标题、摘要、日期、链接。

详情卡常驻两项：

- 分量：弱 / 中 / 强 / 高可信，或清除评级。
- 突破：标记里程碑式的证据，在技能进阶分里额外 +1000。

快速评审：在「待评审」用键盘逐条处理，j / k 移动，a 接受，s 跳过，1 / 2 / 3 设分量为弱 / 中 / 强。

详情卡还显示出处（看板任务、项目、来源类型）、正文全文，以及「更多」里的置信度、公开就绪度、摘录、语言、哈希、ID 等。项目关联在结晶时从任务自动带入，页面上只读。

修改带写入冲突检查：文件在别处被改过时会提示，刷新后再改。

## 技能关联

详情卡的「技能关联」区：

- 已关联的技能显示为标签，点击取消关联。
- 下方最多 5 个建议，标注来源（规则 / 嵌入 / AI），点击即关联。

关联写入 `skill-tree.yaml` 节点的 `evidence_refs`，并同步 `SKILL.md`。建议的技能节点若不存在，会以「在学」新建。

## 待补强

列出证据撑不起当前境界的扎实 / 精通技能，规则和 [技能树](skill-tree.md#技能进阶) 的进阶分一致：

- 只算已审阅、未废弃的证据，按分量计分（默认弱 1、中 10、强 100，突破另加 1000）。
- 扎实要达到「在学 → 扎实」的门槛（默认 30），精通要达到「扎实 → 精通」的门槛（默认 100）。有突破证据时直接算够（可在设置里关掉）。
- 分值和门槛跟着「设置 → 技能进阶」走。

卡片显示「进阶分 X / 门槛，还差 N 分」，以及两个入口：「去挂证据」进入「待关联」，「去结晶」进入「待结晶」。这一阶段只读。完整的档案体检（validate、sync 等）用 CLI `nblane validate`；`GET /health` 接口仍保留给助手和 CLI，用的是同一套规则。
