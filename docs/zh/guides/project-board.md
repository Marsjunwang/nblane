# Project Board 使用说明

Project Board 是内部项目案例页，用来把目标、任务、证据、研究资料、里程碑和输出串起来。

## 什么时候使用

- 一个工作已经超过单张 Kanban 卡，需要长期追踪。
- 需要知道哪些任务、证据或输出属于同一个项目。
- 需要把项目拆成里程碑。

## 推荐流程

1. 创建项目案例，填写状态、类型、可见性和摘要。
2. 关联当前目标、看板任务、证据、研究资料和输出。
3. 有阶段节点时添加里程碑。
4. 使用“新建看板任务”把项目行动落到执行面。
5. 回到 Dashboard 或 Evidence Review 检查是否还有未归属项。

## 写入边界

本页写入 `project-board.yaml`。创建或关联任务时，可能同步更新 `kanban.md`。

## 注意事项

公开项目仍由公开输出层管理。Project Board 是内部工作流，不自动发布。
