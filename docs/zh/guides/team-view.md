# Team View 使用说明

Team View 用于维护团队级配置和共享产品池。

## 什么时候使用

- 更新团队使命、成员、共同规则或当前优先级。
- 沉淀团队共享的问题、项目、证据、方法和决策。
- 查看团队文件的写入范围。

## 推荐流程

1. 选择团队。
2. 确认写入归属和团队范围。
3. 编辑 team.yaml 中的团队信息。
4. 在产品池中维护共享条目。
5. 保存前确认这不是个人 profile 的技能或证据内容。

## 写入边界

本页写入 `teams/<team>/team.yaml` 和 `teams/<team>/product-pool.yaml`。

## 注意事项

个人目标、个人技能和个人证据仍在当前 profile 的页面维护。
