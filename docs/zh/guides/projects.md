# 项目

项目页 `/p/<档案>/projects` 是执行面：任务、项目、里程碑和习惯都在这里。它回答「现在做什么、做到哪、做完怎么变成证据」。旧的 `/kanban`、`/project-board` 链接会跳到这里，参数保留。

## 视图与分组

工具栏有两组切换，状态都写在地址里：

| 切换 | 选项 | 参数 |
|------|------|------|
| 视图 | 泳道看板 / 时间轴 / 大事记 | `view=kanban\|timeline\|story`，默认看板 |
| 分组 | 按目标 / 按活动 | `group=goal\|activity`，默认按目标 |

- 按目标：每个目标一组，标题显示目标日期和摘要；没关联目标的项目归入「未分组」。
- 按活动：按项目类型分组（内部、研究、工作、副业、学习、习惯、习惯计划）。

`task=<id>` 在三个视图里通用，打开该任务的详情卡，切换视图时保留。

工具栏另有「新建项目」「新建计划」「刷新」，下方一行统计：今天日期、任务、未归属、已完成、项目、习惯。在看板视图点「未归属」会滚到未归属泳道。页头的北极星徽章跟随首页的「显真」开关。

## 泳道看板

从上到下：日课栏、各项目泳道、「未归属任务」泳道、归档带。

每条项目泳道：

- 两列 Queue 和 Doing。Someday 卡放在 Queue 列底部。
- Done 不占列，泳道头显示「Done · N」，点开看最近 8 条完成记录。
- 泳道头：项目名、类型、状态、里程碑进度、最近活动日期、编辑按钮。
- 空泳道折叠成一行快速添加。

快速添加：每个 Queue 列顶部的「快速添加」，输入标题回车即建卡，输入框保持打开方便连续添加。只认纯标题，标签、日期等在详情卡里补。

拖拽：同一泳道内可在 Queue 和 Doing 之间拖动和排序。换项目归属在详情卡里改。键盘：卡片获得焦点后 Enter 打开详情，Space 拿起或放下，Esc 取消。触屏长按约 0.25 秒开始拖动，不影响页面滚动。

任务卡显示：标题、标签、日期（有排期时显示排期，否则显示开始或完成日期）、清单进度。

### Someday 与到期激活

Someday 卡是虚线金框，不能拖动，卡上直接有「列入 Queue」和「标记 Done」。给 Someday 卡设排期开始日，相当于「期望激活日」：到了这一天，徽标变成朱砂色的「该激活了」。这只是提醒，卡片不会自动移动。

## 任务详情卡

点任务卡打开详情：

- 状态与日期：队列 / 进行中 / 以后再说 / 已完成，进行中显示已进行天数；开始、完成日期。
- 排期：开始和结束日期，「保存排期」或「清除」。
- TODO 清单：勾选、删除、回车新增，自动保存。
- 编辑：标题、上下文、为什么、归属、标签。归属可以直接改，选「未归属」即移出项目。
- 动作：移至 Doing / 移至 Queue / 以后再说 / 标记 Done、「打卡 · <习惯>」（项目挂了习惯时出现）、「结晶为证据」、删除任务。

删除需要确认，可勾选「记入大事记」。

### Done 之后：结晶为证据

任务完成后，在详情卡点「结晶为证据」，进入证据页的「待结晶」阶段，在那里选任务、生成草稿、确认入库。结晶要求任务有完成日期、关联了项目、项目挂了目标。流程见 [证据](evidence.md)。

## 日课栏与阶段计划

日课栏在看板顶部，每个习惯一行：名称、连续天数、上次打卡、累计次数、本周 7 天打卡点和「打卡」按钮。

- 展开一行看月历热力图：点空格补卡，点已打卡的格子可以销印（删除当天最近一次打卡）。
- 习惯行的齿轮菜单：新建计划、归档 / 恢复、删除（需输入习惯名确认）。底部可切换是否显示已归档习惯。
- 打卡同步到首页的日课印，记录在 `activity-log.yaml`。

阶段计划是给习惯加的一段有起止的计划，比如「28 天减脂」：

- 新建：习惯行齿轮菜单「新建计划…」，填计划名、起止日期（默认 28 天）、挂载项目，然后按天（「第 N 天」，留空为休息日）或按周（「第 N 周」，每行一个任务）排任务。
- 从模板新建：工具栏「新建计划」，选内置模板或用过的模板，可改标题和开始日期，会生成一个习惯计划项目和对应习惯。
- 泳道里的「阶段计划」卡显示进度、完成率、今日任务和本周任务。按周的任务会生成周卡放进 Queue，勾选以周卡为准。
- 打卡时如有进行中的计划，可选择是否计入该计划。
- 删除计划需输入计划名，可选同时删除未完成的周卡、记入大事记。

## 项目

- 新建：「新建项目」，填标题、ID（可留空）、类型、可见性、摘要、关联目标。创建后自动打开编辑抽屉。
- 编辑抽屉三个页签：
  - 基本信息：标题、状态、类型、可见性、时间范围、摘要、备注，以及关联的目标、任务、证据、资料、经历、输出。「AI 建议引用」只预填表单，保存前可以改。
  - 里程碑：标题、状态、目标、日期、摘要。
  - 任务：查看任务，新建任务时可选看板列和里程碑。
- 归档：抽屉里「归档项目」，提示里可以撤销。归档的项目进入页面底部的归档带，点开是只读泳道，可「恢复」。
- 删除：抽屉「危险区」，需输入项目名确认。删除后任务回到未归属，证据上的引用保留为墓碑。

## 时间轴

`view=timeline` 用月轴展示项目和任务：

- 项目时间范围是底块，任务按排期画成条，里程碑是菱形，金色虚线是今天。
- 「历史」层（默认开）用细刻痕显示已完成和已归档的任务。
- 缩放：周 / 月 / 季 / 半年 / 全部，或 Ctrl + 滚轮（含触控板捏合）。滚轮和空白处拖动是平移。
- 拖动任务条即改期。
- 可按项目多选筛选、「聚焦」某个项目的时间范围、「重置视图」、显示归档项目。

## 大事记

`view=story` 是同一份数据的只读回放：S 形逐行折返，新的在上，超过 21 天的空档显示为断轴，过密的标签合并成「+N」，悬停可看全部。

- 键盘：← ↑ k 向现在，→ ↓ j 向过去，Enter 打开详情，Esc 取消。
- 铭文卡上的「去编辑」跳回看板并打开该任务。

## 手机端

窄屏时工具栏随页面滚动，泳道横向滚动（每列约 280px），长按拖卡，习惯行的齿轮常驻显示。

## 数据文件

| 文件 | 内容 |
|------|------|
| `kanban.md` | 任务：列、详情、排期、清单、归属 |
| `kanban-archive.md` | 归档的旧任务（时间轴历史层读取） |
| `project-board.yaml` | 项目、里程碑 |
| `activity-log.yaml` | 习惯、打卡、阶段计划 |
| `chronicle.yaml` | 删除时可选追加的大事记 |
| `plan-templates.yaml` | 你用过的计划模板 |

任务的项目归属在 `kanban.md`（`project_id`）和 `project-board.yaml` 两边同步。修改都带写入冲突检查，文件在别处被改过时会提示「数据已被他人修改」，刷新后重试。

### kanban.md 格式要点

手工编辑或用助手、CLI 写入时按这个格式：

```markdown
# <name> · Kanban

> Updated: 2026-10-07

## Doing

- [ ] 任务标题
  - id: 3f9a2c
  - project_id: my-project
  - started_on: 2026-10-01
  - todo: [ ] 一个清单项

---

## Done

- [x] 已完成的任务
  - completed_on: 2026-10-05

---

## Queue

- (empty)

---

## Someday / Maybe

- 以后再说的想法
  - planned_start: 2026-11-01
```

- 分节：Doing、Done、Queue、Someday / Maybe，用 `---` 分隔，空节写 `- (empty)`。
- 任务行顶格：`- [ ]` 未完成，`- [x]` 完成；Someday 里不带复选框。
- 缩进的 `  - key: value` 是元数据：`id`、`context`、`why`、`blocked by`、`outcome`、`started_on`、`completed_on`、`planned_start`、`planned_end`、`crystallized`、`project_id`、`milestone_id`、`tags`。多行内容用 `|` 块。
- `  - todo: [ ] 文本` 是清单项。其他缩进行算作详情。
- `id` 首次保存时生成，之后不变，证据里的 `kanban:<id>` 引用靠它长期解析。
- 没有 `due` 字段，Someday 的激活日就是 `planned_start`。
