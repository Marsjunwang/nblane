# Projects (pointer)

The Project Board and the Kanban board are now one SPA page: **Projects**
(`/p/<profile>/projects`). It offers three views (`view=kanban`, `timeline`,
`story` chronicle) and two groupings (`group=goal`, `activity`). Old
`/project-board` and `/kanban` links redirect there.

The canonical guide is Chinese: [docs/zh/guides/projects.md](../../zh/guides/projects.md).
